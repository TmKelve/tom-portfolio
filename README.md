# Tom Kelve — Portfólio

Portfólio profissional bilíngue voltado a arquitetura de soluções com Azure, Power Platform, Data e inteligência artificial.

## Destaques

- Hero imersivo com parallax por rolagem e movimento do ponteiro
- Experiência responsiva em português e inglês
- Seções de projetos, experiência, conteúdo e contato
- Preferência de movimento reduzido respeitada nas animações
- Otimização de imagens e rotas estáticas com Next.js

## Tecnologias

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS 4
- next-intl
- Phosphor Icons

## Desenvolvimento local

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000/pt-br](http://localhost:3000/pt-br).

## Validação

```bash
npm run lint
npm run build
```
